## 1. Purpose

M7.6 adds the **second real discovery source**, `EuropePMCDiscoveryProvider`, the
**C2** connector in `docs/24`'s priority order **Crossref → Europe PMC → PubMed**.
It lets WiseEvidence discover and fetch structured bibliographic metadata from
Europe PMC's free, no-key REST API and turn it into provider-neutral discovery
objects — nothing more. It never publishes, classifies, accepts, merges, deletes,
or calls AI, and it adds no database migration.

It reproduces the M7.2 Crossref connector pattern exactly; only the endpoint, the
query dialect, and the response parsing differ. The M7.1 `DiscoveryProvider`
contract is unchanged, and the M7.3 orchestrator drives the new provider through
the registry with no code change.

## 3. Security posture (mirrors M7.2, verbatim machinery)

- **Host pinned** to `www.ebi.ac.uk` via a module constant — never a
  caller-supplied base URL. The only endpoint used is the structured REST `search`
  path. Every request URL is routed through `assertUrlAllowed`.
- **Injected fetch**, HTTPS-only, timeout-bounded (`AbortController`),
  response-size-bounded (streamed cap), `redirect: "error"`, content-type
  validated as JSON. The package never touches an ambient global fetch;
  registering EUROPE_PMC without a fetch fails closed as `NOT_CONFIGURED`.
- **No API key** is required or accepted. No secret is introduced anywhere.
- **Untrusted output**: every field is length-capped/sanitized, DOIs canonicalised
  via `@wise-evidence/domain`, abstract markup reduced to text (never rendered),
  the raw payload reduced to a small whitelist, and errors redacted.
- **Query-injection hardening**: free-text queries are stripped of
  Lucene/Europe-PMC operators and boolean keywords before entering the
  field-scoped query; DOI/`SRC`/`EXT_ID` values are quote-escaped.

## 4. Europe-PMC-specific decisions

- **Composite `SOURCE/ID` stable id.** Europe PMC's persistent identifier is the
  `source`+`id` pair (e.g. `MED/36000001`), used as the idempotency key (fallback:
  canonical DOI). Consequence: unlike the DOI-keyed Crossref connector, a DOI-less
  preprint still gets a stable id and normalizes — a genuine strength of Europe
  PMC's cross-linked id space.
- **Identifiers.** Emits DOI + PMID + PMCID, which strengthen the M7.5 conservative
  dedup downstream.
- **Pagination.** Uses `cursorMark`; because Europe PMC repeats the final page's
  mark, the connector terminates when the page is short, when no next mark is
  offered, or when the mark equals the one sent — no infinite loop.
- **No retries in the connector.** One request per operation; retries/backoff/
  `Retry-After`/scheduling stay with the M7.3 orchestrator. A 429 is a typed
  `RATE_LIMITED`. Rate-limit/size caps are conservative app-level values labelled
  **REQUIRES LIVE VERIFICATION**.

## 5. Boundaries preserved (test-covered)

`DISCOVER → QUEUE → HUMAN REVIEW` only. `DUPLICATE ≠ DELETE` and
`Study ≠ Publication`: a Europe PMC record whose DOI already belongs to a known
study is flagged `DUPLICATE_CANDIDATE` for human review (integration test), never
merged, deleted, or published. The boundary guard proves the connector imports no
AI/database/web/vendor SDK, exposes no generic URL-fetch helper, writes nothing
canonical, and does not leak Europe-PMC-specific code into the generic contracts.
Registry stays selection-based — no `if source === "europepmc"` anywhere.
