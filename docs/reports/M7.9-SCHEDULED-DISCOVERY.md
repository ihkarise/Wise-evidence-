## Goal

Let WiseEvidence run the **existing** discovery engine on a recurring schedule
**safely**, under the trust model: `SCHEDULE → TRUSTED EXECUTION → existing
discovery engine → Crossref/Europe PMC/PubMed → normalize + dedup → candidate
queue → HUMAN REVIEW`. Automation may **find** papers; it must **not decide** what
happens to them. This is achieved with **no in-application scheduler** and **no
migration** — recurrence lives in an external GitHub Actions cron that calls one
trusted endpoint.

## Owner decisions applied

- **Scheduler:** GitHub Actions cron + trusted token-authenticated endpoint
  (owner: no preference → recommended, free-first).
- **Search terms:** fixed server-configured query, default `homeopathy` (owner: no
  preference → recommended).
- **Overlap:** refuse if a run is already `RUNNING` for the source (owner choice).
- **Config store:** server config/env — **no migration** (owner choice).

## Completed

1. `runScheduledDiscovery` — a new composition entry sharing the exact M7.8 wiring
   (`runComposedDiscovery`), differing only in `trigger=SCHEDULED` + the overlap
   guard. No second discovery engine.
2. Overlap guard in `DatabaseDiscoveryStore.createRun`, gated on
   `trigger === "SCHEDULED"`: refuses a same-source in-progress run
   (`invalid-state` → HTTP 409) with no `import_job` row created; manual runs
   unchanged.
3. Pure, framework-independent trusted-invocation auth/config module
   (`service/scheduled-discovery.ts`): constant-time shared-secret check, bearer
   parsing, fail-closed authorization ordering, provider/query resolution.
4. Trusted endpoint `POST /api/internal/discovery/run`: constant-time
   `DISCOVERY_RUN_TOKEN` (unset → 404 disabled) + server-configured real staff
   actor (`DISCOVERY_RUN_ACTOR_ID` → `resolveActor`, non-staff → 403) + closed
   provider allowlist + server-configured query; reuses `runScheduledDiscovery`.
5. External scheduler `.github/workflows/discovery.yml`: `schedule:` cron +
   `workflow_dispatch` + `concurrency:`; POSTs the token, runs no discovery logic,
   cleanly skips when unconfigured, never prints the secret.
6. Config surfaces: `env.d.ts`, `.env.example`, `render.yaml` (opt-in,
   `sync: false`).
7. Documentation: `docs/30` §15, `ADR-020` M7.9 amendment, `docs/22` roadmap,
   `MANIFEST.md`, `CLAUDE.md`, this report.

## Security status

Fail-closed at every step. Caller authenticated by a constant-time shared secret
(never echoed; unset → feature disabled/404). Run executes under a real,
server-resolved staff actor (role never from the request; non-staff → 403).
Query/budget server-controlled; only an allowlisted provider is request-derived;
connectors host-pinned internally. Errors mapped to safe messages; secret-scan of
the diff: only env-var **names** referenced, no secret values committed.
