## Benchmark Method

Identical source input, prompt, prompt version, system instructions, request
settings, max output, and output schema for every model — the only variable is
the model (`AI_BENCH_MODELS`). 3 models × 6 tasks = **18 requests max**; a single
**marked** retry only for a transient transport error. Existing M6 prompt-injection
defenses retained (research text stays wrapped as `UNTRUSTED_RESEARCH_DATA`;
system instructions unchanged, never weakened). Existing M6 validators; validation
never weakened to pass a model. Cache is bypassed for the inference comparison,
then verified separately. Harness: `packages/database/src/m6-1-benchmark.test.ts`
(mock-validated offline; matrix, per-model FULL(6) + ESSENTIAL(4) cost, per-output
dump, and cache-HIT confirmed).
