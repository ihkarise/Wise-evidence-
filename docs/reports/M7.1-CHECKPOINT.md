## Discovery Architecture

`packages/discovery` is a framework-independent module (modular monolith,
`ADR-001`) alongside `packages/{domain,metadata,ai,benchmark}`. It imports nothing
from Astro, React, Supabase, web UI, or any AI SDK; among workspace packages it
depends only on `@wise-evidence/domain` (DOI/title canonicalisation). Three
metadata tiers are kept separate: raw untrusted (`SourceItem`), sanitized/
canonicalised (`NormalizedSourceItem`), and — absent in M7.1 — AI-derived and
human-authored. No outcome/quality/criticism/confidence/efficacy/score field
exists anywhere (`RELEVANCE ≠ EFFICACY`).

## Provider Contract

`discover(request) → DiscoveryResult<DiscoveryPage>` (paged via opaque cursor),
`fetch(ref) → DiscoveryResult<FetchResult>` (enrichment, never acceptance), and
`normalize(item) → DiscoveryResult<NormalizedSourceItem>` (pure, synchronous).
Expected failures are returned as typed `DiscoveryError`s, never thrown. The
contract holds no Crossref-specific concept, so an M7.2 adapter plugs in
unchanged.

## Mock Provider

`MockDiscoveryProvider` — deterministic (fixed injected clock, no randomness),
offline, fixture-backed. Covers successful discovery, multiple pages, empty
result, duplicate item (surfaced, never deleted), malformed item, missing DOI,
invalid DOI, fetch failure, timeout, and rate limiting. It is injectable
(constructor options for key/descriptor/dataset/clock/version/rate budget).

## Registry

`DiscoveryProviderRegistry` maps a provider type to a factory;
`createDefaultDiscoveryRegistry()` registers MOCK only. Resolving CROSSREF /
PUBMED / EUROPE_PMC throws `DiscoveryError("NOT_CONFIGURED")`. No fake connector
behaviour, no network call.

## Security

- Host/URL egress gate (`assertUrlAllowed`) enforces allow-list + HTTPS +
  no-credentials + no private/loopback (unless opted in); it returns/throws and
  **never fetches**. No generic "fetch any URL" helper exists.
- Descriptors carry no secret-shaped field (tested).
- Error messages are redacted so a secret cannot leak.
- Source metadata is treated as untrusted and never emitted as markup.

Tests prove: arbitrary host rejected; HTTPS policy represented and enforced;
secrets absent from public config; provider errors do not expose secrets; no
arbitrary-URL fetch capability.

## AI Boundary

`boundary.test.ts` scans the package source and asserts it imports nothing
matching `@wise-evidence/ai` or any vendor AI SDK, and that its only workspace
dependency is `@wise-evidence/domain`. Discovery remains fully functional with AI
absent (`AI ≠ AUTHORITY`).

## Database Boundary

M7.1 performs no `research_study` / `publication` / `classification` insert and no
publication state change; `boundary.test.ts` asserts no canonical-write SQL and no
`@wise-evidence/database` import. The existing `research_source` / `import_job` /
`import_candidate` / `research_identifier` schema already accommodates the future
candidate flow, so **no migration is added**.
